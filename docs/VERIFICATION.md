# Проверка и оставшиеся ограничения

## Реализовано

- Два экрана по PDF: paywall и подтверждение. Исходная иллюстрация SVG, локальные шрифты Nunito, иконки из переданного векторного листа.
- Годовой тариф 1 990 ₽, месячный 299 ₽. Выбор обновляет кнопку и условия; обе кнопки завершения возвращают к тарифам.
- Загрузка, недоступная кнопка, состояние нажатия, ошибка покупки и повторная попытка, загрузка/ошибка восстановления, отсутствие покупки.
- API и настоящая SQLite-база; отдельный адаптер Neon и миграция PostgreSQL.
- Серверная проверка входных данных, серверная цена, защита от повторной записи запроса, проверка origin, HttpOnly cookie и отсутствие кеширования персональных ответов.
- Управление клавиатурой, фокус после смены экрана, сообщения для screen reader, reduced motion, safe-area и прокрутка коротких экранов.

## Автоматические проверки

Команды: `npm run lint`, `npm run typecheck`, `npm run build`, `npm run build:vercel`, `npm test`.

Финальный результат: линтер и TypeScript без ошибок, обе production-сборки успешны, **18 из 18 тестов прошли**. Vercel-артефакт содержит серверную функцию с runtime `nodejs24.x`.

Playwright проверяет:

- размеры 320/360/390/430/1280 px, отсутствие горизонтального скролла и ошибок JS;
- оба тарифа, подтверждение и обе кнопки возврата;
- восстановление после перезагрузки и отсутствие чужих/истёкших покупок;
- восстановление после полного перезапуска серверного процесса;
- реальные записи в SQLite и конкурентные повторы без дубликатов;
- потерянный ответ уже выполненной покупки и безопасный повтор;
- ошибки API, загрузку, повторную попытку и блокировку выбора во время покупки;
- некорректные входные данные, подмену цены и cross-origin POST;
- клавиатуру, небольшой экран и конец месяца/високосный год.

Скриншоты создаются в `test-results/`. Проверка выполнена в Chromium; публичный деплой и реальные мобильные webview не проверены.

## Что ещё требуется

1. **Публичная публикация и удалённый репозиторий.** Доступы Vercel/Neon/GitHub не предоставлены. Серверная сборка Vercel готова, но публичного URL пока нет.
2. **Проверка Neon на реальном аккаунте.** Миграция и адаптер написаны; локальные интеграционные тесты используют SQLite. Доступы нужны для проверки PostgreSQL и записи после деплоя.
3. **Figma и точность.** Исходный Figma недоступен через MCP из-за лимита. Выполнено визуальное сравнение с PDF 1:1, уточнены размеры и отступы. Численное совпадение «99%» не подтверждено; сглаживание шрифтов PDF/браузера различается. Иконки берутся из предоставленного SVG-набора, хотя в PDF некоторые значки набраны текстом.
4. **Зависимости.** После установки исправленного `simple-git@4.0.2` через scoped override для отключённых Nuxt DevTools критических предупреждений npm audit нет. Остаются 11 high в дереве зависимостей, связанные с `braces@3.0.3` и `node-forge@1.4.0`; на момент проверки это последние версии этих пакетов. Не применялись принудительные откаты Nuxt. Перед публичной эксплуатацией повторить аудит и оценить применимость предупреждений.

В рамках учебного задания нет авторизации, настоящей игры, настоящих платежей, межустройственного восстановления и автоматического продления. Приложение не списывает деньги.
